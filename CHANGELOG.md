## Unreleased

## 0.0.1: MVP — portable agent continuity and a runnable WASM reference

- Portable `raiv` library (`no_std + alloc`, Rust1.85): bounded fixed-profile CID/DRISL records, borrowed checkpoint restoration/context projection, registered RAM Activation, resource accounting and validated immutable commit candidates. Core performs no external I/O or trusted host acceptance.
- Organic Memory: exact sparse `intents`/`strategy`/`tactics` patches, atomic selected-content validation, merge/delete/array semantics and complete processed/skipped/change feedback. No synonym remapping, transcript journal or silent checkpoint migration.
- Natural completion: complete correlated zero-tool-call replies seal intrinsic Finish, including silent finals. Local calls Continue and external calls Yield; malformed, refused, incomplete, truncated and exhausted inference never becomes completion.
- Isolated import-free Rust WASM guest and native Wasmi2 bridge: bounded versioned CBOR ABI, retained activation, private request correlation, explicit native admission/candidate acceptance and no production native-guest fallback.
- Linux local durability and conservative recovery: held no-follow directories, exact-byte publication/CAS, Reserved→Attempted→Launched accounting and separately pinned adoption. Uncertain outcomes never authorize automatic relaunch/refund or effect replay.
- Reference application: Bash `./run.sh`, two-region TUI and Go/deepseek-v4.1-flash/high inference with a1024-token bounded envelope. Real-provider textual acceptance, Memory patch and fresh-process semantic recall are verified; native reasoning remains private same-Run RAM. Old failed namespaces are preserved; the new default is `var/raiv/chat`.
- Scripted retry-and-sleep scenario and an independent synthetic unit world: durable pending/terminal records and exact installed-Receipt continuation demonstrate local lifecycle composition without real trading, funding or scheduler authority.
- Release packaging: public `raiv 0.0.1` crate; host/guest packages remain repository applications. Independent fixtures/upstream attribution, Core/guest MSRV1.85 and host MSRV1.86 are preserved. Host checked atomic IDs use a stable/MSRV-compatible implementation after the GitHub stable CI lint caught a standard-library deprecation; exhaustion still fails without wrapping. The owner removed the redundant documentation checksum-manifest gate; source-response provenance remains documented. Specification table separator cleanup changes Markdown only, not requirements, wire bytes or hash domains.

### Support boundaries

This is a bounded working MVP, not production or financial/blockchain readiness. Real pricing/funding, external Actor/Receipt authentication, global/current acceptance, CAR/IPFS/provider-loss availability, full fuzz/resource/acceptance coverage and physical-terminal/async-interruption evidence remain open in BACKLOG. The UI uses synchronous bounded inference; exit is deferred during a call. Local fsync/SIGKILL tests are not physical power-loss or global finality proof.
