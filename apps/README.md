# Applications

Application packages compose the portable [Core](../lib/README.md); they do not add dependencies to its runtime graph.

- [Reference agent](raiv-agent/README.md): Import-free Rust guest and finite Wasmi native bridge. Scripted retained reply/candidate progression, local acceptance/adoption and a synthetic atomic unit-world ledger are implemented as library/test ports. The Linux executable supports scripted init/status and explicitly pinned independent-world provisioning/inspection; scripted wake reaches one durable accepted boundary, separate synthetic pending execution is runnable, ledger-bound resume is runnable, and the fixed actual-WASM retry-and-sleep/fresh-adoption/second-wake runner is runnable; external/live adapters and real tool semantics remain in [BACKLOG.md](../BACKLOG.md).
